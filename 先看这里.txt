公考职位查询工具 · 先看这里
================================================

这是一个「本科 · 生物科学（师范） · 江苏」的公考职位筛选工具，
筛选国考（国家公务员考试）和江苏省考中适合报考的岗位。

【最快用法：双击桌面上的「公考职位查询」快捷方式】

   如果桌面上还没有，双击项目里的 创建桌面快捷方式.bat 就会生成一个，
   以后从桌面直接打开即可。

   快捷方式会做两件事：
     · 电脑装了 Python 3 → 启动本地服务并用浏览器打开（自动读取最新 data.json）
     · 没装 Python      → 直接用浏览器打开页面（使用页面自带数据，功能一样全）

【四种打开方式，任选一种】

1) 双击桌面快捷方式「公考职位查询」            ← 推荐
2) 双击 index.html                            ← 零配置，断网也能用
3) 双击 启动.bat                              ← 等价于方式 1
4) 把职位表 Excel 拖到 更新数据.bat 上         ← 换成真实数据

【更新成真实的职位数据：两种办法】

   办法一（需要 Python 3，最省事）：
     把官网下载的职位表 .xlsx 拖到 更新数据.bat 上，按提示回车。

   办法二（完全不需要 Python，推荐没装 Python 的同学）：
     直接在页面里上传：
       ① 双击 index.html 打开页面
       ② 点上方按钮「选择职位表（Excel / CSV）」
       ③ 选中官网下载的 .xlsx 文件
     页面会用内置的 SheetJS 在浏览器里解析（项目自带 xlsx.full.min.js，无需联网），
     解析完就能筛选、导出 CSV。

   官网下载地址：
       国考：    http://bm.scs.gov.cn/kl2026
       江苏省考：https://www.jszzb.gov.cn/

【页面上怎么筛】

   城市      新增：13 个设区市 + 省级机关（区县/县级市会自动归到所属市）
   工作地点  默认勾选「江苏」
   学历      默认勾选「本科」
   专业匹配  默认勾选「生物科学 / 生物科学类 / 基础理学类 / 教育类 / 不限专业」
   其他      可按身份、政治面貌、基层年限、教师资格证、师范类等进一步筛选
   关键词    例如输入「生物 教师 南京」
   导出      点「导出当前筛选结果 CSV」，用 Excel 打开即可

【匹配结论怎么看】

   A 完全匹配          专业目录明确包含生物科学相关专业
   B 可能匹配/需核实    属于教育类，或额外要求师范类、教师资格证
   C 不限专业          任何专业都能报
   D 条件不符但相近    专业相近但未明确列入，或学历等条件不符

   凡是标注「⚠ 需电话咨询招录单位」的，都要打咨询电话确认，
   尤其是毕业证专业名称是「生物科学（师范）」的情况——
   各省对「师范」后缀的认定口径不一样。

【重要提醒】

   · 本工具只做筛选辅助，报名条件一律以官方公告、职位表原件和招录单位答复为准。
   · 现在 data.json 里已经是【真实数据】：江苏省2026年度考试录用公务员官方职位表
     （省级机关 + 13 市 + 垂管单位，共 6157 个职位，按生物相关收窄并剔除定向岗位后收录 497 条）。
     官方一发布新年度职位表，工具会自动抓取并替换掉旧年度。
   · 年度别填错：文件名里没有年份时，工具会提示"未能从文件名识别年度"，重做一次填上即可。
   · 更多说明（GitHub 自动更新、部署到网页、常见问题）见 README.md。

【新年度自动替换 / 手动检查】

   · 默认只保留每类考试的【最新年度】：官方一发新年度职位表，旧年度会被自动替换；
   · 想手动确认有没有发布：双击 检查新职位表.bat（会告诉你 2027 是否已发布）；
   · 每条职位现在大多带有【咨询电话】（取自官方《招录单位咨询电话》，覆盖率约 68%，
     其余是电话表里没列明的单位，如「乡镇机关」「区教育局」）。
