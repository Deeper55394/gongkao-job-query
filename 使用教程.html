公考职位查询工具 · 使用教程

面向对象：本科 · 生物科学（师范）专业 · 想报考江苏地区国考/江苏省考岗位的同学。 全程不需要编程基础，照着做即可。

0. 一分钟上手

工具提供了几种打开方式，任选一种就行：

你想要的效果 双击这个文件 需要什么
从桌面一键打开创建桌面快捷方式.bat（生成桌面快捷方式）什么都不用装
马上看看有哪些岗位、能不能筛index.html什么都不用装，断网也能用（页面自带真实数据）
用最新的职位数据筛选启动.bat电脑装了 Python 3（没装会自动退回上一种）
把官网的真实职位表换成工具的数据更新数据.bat（把 Excel 拖上去）电脑装了 Python 3（会自动装依赖）

第一次用，建议顺序：先双击 创建桌面快捷方式.bat 生成桌面图标 → 再拖一张真实职位表进 更新数据.bat → 以后从桌面一键打开。

0.1 生成桌面快捷方式

双击 创建桌面快捷方式.bat，桌面就会出现带图标的「公考职位查询」快捷方式。

  • 电脑装了 Python 3：它会启动本地服务并用浏览器打开，自动读取最新的 data.json（黑窗口会最小化，用完关掉即可）；
  • 没装 Python：它直接用浏览器打开页面，用页面自带数据，筛选、导出功能完全一样。

想要第二个"更新数据"的快捷方式，就在命令行执行 创建桌面快捷方式.bat both。

如果之后移动了项目文件夹，快捷方式会失效，重新双击一次 创建桌面快捷方式.bat 即可修复。 没有 Python 也能用真实数据：打开页面后点「选择职位表（Excel / CSV）」，直接选官网下载的 .xlsx —— 项目自带 xlsx.full.min.js，离线就能在浏览器里解析。

1. 第一次打开

1.1 双击 index.html（零配置）

打开后你会看到：顶部标题和「数据最后更新」时间 → 中间是筛选条件 → 下面是职位表格（手机上自动变成卡片）。

如果顶部出现黄色提示"已自动载入页面内置数据"，这是正常现象，不是出错：

  • 浏览器出于安全策略，禁止网页在 file:// 模式下读取同目录的 data.json；
  • 工具于是用了"内嵌在页面里的数据"兜底，筛选、查看、导出 CSV 全部照常可用；
  • 想让页面自动读取最新数据，用下面 1.2 的方式。

1.2 双击 启动.bat（推荐日常使用）

会弹出一个黑色窗口，并自动打开浏览器（地址形如 http://127.0.0.1:8765/）。这个方式下页面会自动读取同目录的 data.json，效果和你把工具部署到网上完全一样。

  • 想换端口：把这个 .bat 拖到命令行执行 启动.bat --port 9000；
  • 想让手机也能打开：先用 启动.bat --lan 启动，窗口里会打印一个形如 http://192.168.x.x:8765/ 的地址，手机连同一个 WiFi 就能访问；
  • 用完直接关掉黑窗口即可（或按 Ctrl + C）。

如果电脑没装 Python，这个 .bat 会提示找不到 Python，并自动改用 1.1 的方式打开页面 —— 功能不受影响。

1.3 手机上打开

两种办法：

  1. 局域网：电脑上执行 启动.bat --lan，手机浏览器打开打印出来的那个 http://192.168.x.x:8765/；
  2. 部署到网上（推荐，一劳永逸）：见本文第 6 节，部署后任何设备打开同一个网址即可。

2. 把真实职位数据装进工具（核心步骤）

data.json 里现在已经是真实数据：江苏省2026年度考试录用公务员官方职位表（497 条与生物科学（师范）相关的职位）。官方发布新年度职位表后，工具会自动抓取并替换旧年度。

2.2 把 Excel 拖到 更新数据.bat 上

用鼠标把刚下载的职位表文件拖到 更新数据.bat 的图标上，松手。窗口会依次问你三件事：

考试类型（可填 国考 / 江苏省考）（回车=江苏省考）:      ← 直接回车
年度（留空=自动识别）:                                  ← 建议手动填，如 2026
官方公告页网址（可留空）:                                ← 建议把公告页网址粘进来

填完后它会自动完成：检查依赖 → 解析清洗 → 生成 data.json → 同步进 index.html。

看到「完成！data.json 与 index.html 均已更新」就成功了，按回车关掉窗口。

年度一定要填对：如果文件名里没有年份（例如"职位表.xlsx"），工具识别不出年度，会提示"未能从文件名识别年度，将按 XXXX 年处理"。这时候重新拖一次、在"年度"里填上真实年份即可。

2.3 命令行方式（批量、多文件）

# 单个文件
python scraper.py --local "2026江苏省考职位表.xlsx" --exam-type 江苏省考 --year 2026 --source-url "https://www.jszzb.gov.cn/公告页.html"

# 多个文件一起（会自动合并，并按"考试类型+年度+职位代码"去重）
python scraper.py --local 省考职位表.xlsx 国考职位表.xlsx --exam-type 江苏省考 --year 2026

# 同步进 index.html（让双击打开也能看到新数据）
python tools/build_standalone.py

2.4 怎么确认数据真的更新了

打开页面看两个地方：

  • 顶部「数据最后更新」是否变成刚才的时间；
  • 顶部右侧是否还有红色「示例数据」角标 —— 换成真实数据后角标会消失。

3. 筛选岗位

3.1 默认帮你选好了什么

打开页面时已经默认勾选了：

  • 考试类型：国考 / 江苏省考（选项随数据自动出现；目前 data.json 里只有江苏省考数据）
  • 工作地点：江苏
  • 学历：本科
  • 专业匹配：生物科学、生物科学类、基础理学类、教育类、不限专业

每个选项后面的小数字是"在当前其他条件下，勾上它能命中多少条"，可以避免勾了半天筛出 0 条。

3.2 常用筛选组合

你的情况 建议勾选
我是应届毕业生（不含择业期）身份：应届（身份"不限"的岗位会自动保留）
我是两年内未就业的择业期毕业生身份：应届 + 择业期
我已是往届/在职身份：往届 + 不勾身份（留空=不限制）
非党员政治面貌：共青团员 + 群众（"不限"的岗位会自动保留）
没有基层工作经历基层经历：无
我已有生物学科教师资格证其他：要求教师资格证（专门看这类岗位）
只想看最稳的其他：A 完全匹配
想知道还有哪些能争取的其他：B 可能匹配

3.3 关键词搜索技巧

关键词框支持空格分隔的多个词，必须同时命中（会搜职位名称、招录机关、专业原文、其他条件、备注、工作地点）：

  • 生物 教师 —— 生物相关且和教师有关
  • 南京 中学 —— 南京的中学岗位
  • 教师资格 —— 其他条件里提到教师资格证的岗位
  • 不限专业 —— 专业不限的岗位

3.4 手机上的操作

屏幕窄的时候表格会自动变成卡片，一张卡片一个岗位，向下滑即可；筛选条件在页面上方，点「收起 / 展开」可折叠。

4. 看懂「匹配结论」

每条职位的最后一列是结论，共四类：

结论 含义 你要做什么
A 完全匹配专业目录明确包含「生物科学 / 生物科学类 / 基础理学类」，学历等硬条件不冲突直接进入备选清单
B 可能匹配 / 需核实属于教育类，或专业匹配但额外要求师范类 / 教师资格证打咨询电话确认
C 不限专业专业不限，任何专业都能报竞争通常较大，可作为保底
D 条件不符但相近专业相近但未明确列入目录，或学历要求硕士等硬条件不符一般放弃，或打电话问"相近专业能否报考"

4.1 为什么"生物科学（师范）"总提示要打电话

各省的《专业目录》对带「师范」后缀的专业认定口径不一致：

  • 有的省份认为「生物科学（师范）」就是「生物科学」，可以直接报；
  • 有的省份认为它是独立专业名称，需要招录单位明确认可"视为同一专业"。

工具无法替招录单位做认定，所以只要专业原文里出现「师范」，就会标注 ⚠ 需电话咨询招录单位。这是为你负责，不是工具在推卸。

4.2 咨询电话怎么打（照读即可）

您好，我准备报考〔单位名称〕的〔职位名称〕（职位代码〔代码〕）。 我的本科毕业证专业名称是「生物科学（师范）」，请问是否符合贵单位该职位的专业要求？ 如果需要，我可以提供学校出具的专业目录对照说明。

另外想确认两点：一是该职位要求的教师资格证是报名时就必须具备，还是录用前取得即可；二是〔学历/学位/户籍/基层经历〕这项我的情况是〔你的情况〕，是否符合？

打电话问到的结论，建议在导出的 CSV 里补一列备注，避免记混。

5. 导出、打印、分享

5.1 导出成 Excel 能看的表格

点「导出当前筛选结果 CSV」，会下载一个形如 公考职位筛选结果_7条_20261001_1030.csv 的文件：

  • 导出的是当前筛选后的结果，不是全部数据；
  • 文件带 UTF-8 BOM，双击用 Excel 打开不会乱码；
  • 表尾多了三列：匹配结论、匹配说明、需电话咨询，方便你逐个打电话核实。

5.2 打印 / 另存为 PDF

浏览器里 Ctrl + P，打印样式会自动隐藏筛选面板，只留结果表格。

5.3 发给同学 / 换电脑

  • 发一个文件就够：把 公考职位查询_单文件版_日期.html 发过去，对方双击即可用（数据就在文件里）；
  • 发整个工具：发 公考职位查询工具_日期.zip，对方解压后双击 index.html；
  • 这两个文件都可以用 python tools/make_package.py 重新生成（每次更新数据后重新生成一次，分享的就是最新数据）。

5.4 多设备同步（部署到网上）

见第 6 节，部署完成后手机、平板、公司电脑打开同一个网址即可，数据由 GitHub 每天自动更新。

6. 部署到 GitHub Pages（可选，但推荐）

一次配置，长期受益：任何设备打开一个网址就能用，而且每天自动更新数据。

  1. 注册/登录 GitHub，新建一个仓库（建议选 Public 公开）；
  2. 把本项目全部文件推到仓库（不会用 Git 的话，直接在仓库页面用 "uploading an existing file" 把文件拖上去也可以）； 注意要保留 .github/workflows/update.yml 和 .nojekyll 这两个文件；
  3. 进入仓库 Settings → Actions → General → Workflow permissions，选 Read and write permissions 并保存（否则机器人没法把新数据写回仓库）；
  4. 进入 Settings → Pages → Build and deployment → Source，选择 GitHub Actions；
  5. 打开 Actions 标签页，选「自动更新公考职位数据」，点 Run workflow 手动跑一次，确认变绿；
  6. 稍等一分钟，访问 https://你的用户名.github.io/仓库名/ 即可使用。

之后它会在每天北京时间 10:00（UTC 02:00）自动检查官网有没有新职位表，有就更新并重新部署。

7. 自动更新是怎么工作的

scraper.py 会：

  1. 访问国家公务员局国考专题、江苏先锋网、江苏省人社厅、各设区市人社局的公告页；
  2. 找出其中的职位表附件（.xlsx / .xls / .zip）并下载；
  3. 用 pandas 解析、清洗、按"生物科学（师范）"打专业标签、计算 A/B/C/D 结论；
  4. 合并历史数据（按"考试类型+年度+职位代码"去重），写出 data.json。

它的行为规范：只访问官方域名白名单；遵守 robots.txt；同一域名请求间隔至少 3 秒；失败重试采用指数退避；抓不到数据时绝不覆盖已有 data.json，也绝不编造数据。

重要现实提醒：GitHub 的服务器在境外，政府网站经常限制境外 IP 访问，所以定时任务可能长期抓不到。这不是工具坏了，遇到这种情况直接用第 2 节的办法：本机下载 Excel → 拖进 更新数据.bat → 提交 data.json。

9. 数据来源与免责声明

  • 数据全部来自官方公开发布的职位表：国家公务员局、江苏先锋网、江苏省人力资源和社会保障厅、各设区市人社局；
  • 工具不会生成、推断或修改任何职位信息，专业要求字段逐字保留官方原文；
  • 匹配结论只是筛选辅助，不构成报考建议；
  • 报名资格最终以官方公告、职位表原件以及招录单位答复为准。凡是提示"需电话咨询招录单位"的，请务必打电话确认。
